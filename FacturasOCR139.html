⚙ Configuración de Google Sheets

🔴
Sin conectar
Seguí los pasos para configurar
1
Pegá la URL de tu Web App de Google

Si ya la tenés, pegala acá. Si no, seguí los pasos de abajo para crearla.

Si todavía no creaste el script, seguí estos pasos (5 minutos):

2
Ir a Google Apps Script

Abrí script.google.com → clic en + Nuevo proyecto

3
Pegar el código del script

Borrá todo el código existente y pegá el contenido del archivo google_apps_script.js que viene junto a este HTML

4
Guardar e implementar

💾 Guardar (Ctrl+S) → nombre: Facturas OCR
📦 Implementar → Nueva implementación
Tipo: Aplicación web
Ejecutar como: Yo
Quién tiene acceso: Cualquier persona
→ Clic en Implementar → Autorizar → Copiar la URL

5
Pegar la URL arriba y hacer clic en Conectar

La URL tiene este formato:
https://script.google.com/macros/s/AKfycb.../exec
